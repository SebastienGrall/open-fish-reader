# Construction Windows

Prérequis : Windows 10/11 x64, environnement virtuel actif, Inno Setup 6, icône ICO et LICENSE.

```powershell
.\build_installer.ps1
```

Résultats :
- `dist/Open Fish Reader/` : version portable onedir
- `installer_output/OpenFishReader-X.Y.Z-Setup.exe` : installateur

Tester l'installateur sur un poste sans Python avant la V1.
